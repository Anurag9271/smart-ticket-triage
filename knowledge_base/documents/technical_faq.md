# NovaDesk Customer Support – Technical FAQ

> **Demo knowledge base:** NovaDesk is a fictional company used for this project. The policies below are sample policies created for testing the Smart Customer Support Ticket Triage & Auto-Responder.

## 1. Why does the application crash when I open it?

Application crashes may be caused by outdated application versions, browser compatibility issues, corrupted cached data, or temporary service problems. Customers should restart the application, verify that they are using a supported version, and try again. If the issue continues, support should collect the error message, device or browser details, and steps to reproduce the crash.

## 2. Why does report export fail?

Report exports may fail because of large datasets, temporary service issues, browser interruptions, or insufficient permissions. Customers should retry the export, check their permissions, and try a smaller date range if possible. If the issue persists, support should request the report type, selected date range, and error message.

## 3. The dashboard is loading slowly. How can I fix it?

Customers can refresh the dashboard, check their internet connection, close unnecessary browser tabs, and clear cached browser data if appropriate. If the dashboard remains slow, support should collect the affected page, approximate time, browser details, and whether other users experience the same issue.

## 4. I cannot log in even though my password is correct. What should I do?

Customers should verify that they are using the correct registered email address, check whether Caps Lock is enabled, and attempt a password reset. They should also check whether the account is temporarily locked. If login continues to fail, support should investigate the account status and authentication errors.

## 5. Which browsers should I use?

For this demo project, customers should use a recent version of Chrome, Firefox, Edge, or Safari. Keeping the browser updated helps improve compatibility and security. If a problem occurs in one browser, customers can test another supported browser to help identify the issue.

## 6. What information should I provide when reporting a technical issue?

Customers should include a clear description of the problem, the steps that caused it, the expected behavior, the actual behavior, any visible error message, and the approximate time of occurrence. Browser or device details and screenshots can also help support investigate the issue. Customers should avoid sharing passwords, authentication codes, or sensitive payment information.
